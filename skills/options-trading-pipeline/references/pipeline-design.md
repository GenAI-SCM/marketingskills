# Options Trading Pipeline — 최적 설계 (Unusual Whales 기반)

## 설계 철학

기존 접근: **차트 먼저 → 30종목 기술분석 → 옵션 체인 확인**
최적 접근: **플로우 먼저 → 스마트머니가 지금 베팅하는 곳 → 기술분석으로 확인**

핵심 전제:
- `get_flow_alerts` 하나가 기술분석 30종목을 대체한다
- 마켓메이커 포지션(GEX)이 주가의 실제 인력/척력을 만든다
- 다크풀 레벨이 기관 평단가 = 실질 지지선이다

## 7-Layer 데이터 파이프라인

```
┌─────────────────────────────────────────────────────────┐
│  LAYER 0  시장 레짐 판단  (3 calls, 항상 먼저)           │
└─────────────────────────────────────────────────────────┘

  get_market_state()
    → 장 상태, VIX 레벨, 시장 개장 여부

  get_market_tide()
    → 전체 콜/풋 프리미엄 흐름
    → 콜 우세/풋 우세 → 오늘 전략 방향 결정

  get_greek_exposure_by_ticker("SPY") + ("QQQ")
    → 시장 전체 GEX 환경 파악
    → GEX 양수: 마켓메이커 델타 헷지로 변동성 억제 → 스프레드 유리
    → GEX 음수: 마켓메이커 같은 방향 헷지 → 방향성 폭발 → 프리미엄 매수 최적

  ┌──────────────────────────────────────┐
  │ OUTPUT: 오늘 환경 판정               │
  │   GEX 음수 + Tide 불리시 → CALL 풀사이즈 │
  │   GEX 음수 + Tide 베어리시 → PUT 풀사이즈│
  │   GEX 양수 → 사이즈 50% 축소         │
  │   VIX > 35 → 전체 포지션 보류        │
  └──────────────────────────────────────┘

┌─────────────────────────────────────────────────────────┐
│  LAYER 1  플로우 디스커버리  (1 call, 가장 중요)         │
└─────────────────────────────────────────────────────────┘

  get_flow_alerts()
    → 오늘 이상 옵션 플로우 발생 종목 전체
    → 프리미엄 $50k+ 대형 주문 필터
    → 마스터 30종목과 교집합 추출

  ※ 이 한 번의 호출이 "30종목 기술분석 전부"를 대체한다
    시장이 스스로 오늘 주목할 종목 5~10개를 알려준다

  ┌──────────────────────────────────────┐
  │ OUTPUT: 오늘의 관심 종목 5~10개      │
  │   (이하 이 종목들만 심층 분석)        │
  └──────────────────────────────────────┘

┌─────────────────────────────────────────────────────────┐
│  LAYER 2  확신 스태킹  (관심 종목당 4 calls)             │
└─────────────────────────────────────────────────────────┘

  각 관심 종목에 대해 독립적 신호 4개를 쌓아 확신 점수 산출

  ① get_ticker_lit_flow(ticker)
       → 장내(lit) 옵션 플로우 방향 확인
       → 콜 볼륨 vs 풋 볼륨, 대형 주문 포함 여부
       → 신호: 일치하면 +1점

  ② get_interval_flow(ticker)
       → 시간대별 플로우 집계
       → 플로우가 가속 중인지 (최근 1시간 급증) 확인
       → 신호: 가속 중이면 +1점

  ③ get_dark_pool_trades(ticker)
       → 기관 블록 거래 존재 여부
       → 방향(매수/매도), 규모, 가격대
       → 신호: 플로우와 같은 방향이면 +1점

  ④ get_open_interest_changes(ticker)
       → OI 급증 → 새 포지션 오픈 (확신)
       → OI 감소 → 포지션 청산 (방향 약화)
       → 신호: OI 급증(+20% 이상)이면 +1점

  ┌──────────────────────────────────────┐
  │ 확신 점수 (0~4점)                    │
  │   4점: 최강 확신 → 전진              │
  │   3점: 강한 확신 → 전진              │
  │   2점: 보통 → 관망 리스트            │
  │   0~1점: 노이즈 → 제외               │
  └──────────────────────────────────────┘

┌─────────────────────────────────────────────────────────┐
│  LAYER 3  가격 레벨 인텔리전스  (확신 3점+ 종목당 3 calls) │
└─────────────────────────────────────────────────────────┘

  ★ 이 레이어가 "어디로 갈 것인가"를 답한다

  ① get_greek_exposure_by_strike(ticker, expiry=W+3)
       → 행사가별 GEX 분포
       → GEX 절벽(cliff) 레벨: 이 가격 돌파시 변동성 폭발
       → GEX 벽(wall) 레벨: 이 가격이 저항/지지로 작동
       활용:
         - 콜: 현재가 위의 첫 번째 GEX 절벽이 타겟
         - 풋: 현재가 아래의 첫 번째 GEX 절벽이 타겟
         - 행사가는 GEX 절벽 직전 선택 (돌파 전에 이미 수익)

  ② get_max_pain(ticker, expiry)
       → 맥스페인 = 옵션 매도자(마켓메이커)가 가장 유리한 만기 주가
       → 주가가 맥스페인보다 많이 위: 하락 압력 존재 → PUT 유리
       → 주가가 맥스페인보다 많이 아래: 상승 압력 존재 → CALL 유리
       → 주가 ≈ 맥스페인: 중립, 진입 비추

  ③ get_dark_pool_volume_price_group(ticker)
       → 가격대별 다크풀 거래량 분포
       → 가장 많이 거래된 가격대 = 기관 평단가 = 실질 지지선
       활용:
         - 콜 진입: 다크풀 집중 레벨 위에서 진입 (지지 확인)
         - 풋 진입: 다크풀 집중 레벨 아래로 이탈 시 진입

  ┌──────────────────────────────────────────────────────┐
  │ OUTPUT: 종목별 가격 맵                                │
  │                                                      │
  │  예시 NVDA $130 기준:                                 │
  │  ├── GEX 벽(저항): $135 (돌파하면 $140까지 가속)      │
  │  ├── 다크풀 지지: $128 (기관 평단가, 지지선)          │
  │  ├── 맥스페인 W+3: $132 (현재가 아래 → CALL 유리)    │
  │  └── 타겟 레벨: $134 (GEX 절벽 직전)                 │
  └──────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────┐
│  LAYER 4  기술적 확인  (종목당 2 calls)                  │
└─────────────────────────────────────────────────────────┘

  플로우/GEX/다크풀 신호를 기술적으로 확인하는 레이어
  (리드가 아니라 컨펌 역할)

  ① get_ticker_indicator_events(ticker)
       → MA 크로스오버, MACD 크로스 이벤트 감지
       → 직접 계산 없이 이벤트로 제공
       → 플로우 방향과 기술적 방향이 일치하면 확신 추가

  ② get_extended_technical_indicator(ticker)
       → VWAP, 볼린저밴드, 기타 고급 지표
       → 가격이 VWAP 위/아래 확인
       → 볼린저밴드 돌파 여부

  ┌──────────────────────────────────────┐
  │ 기술 컨펌 (0~2점 추가)               │
  │   MACD 골든크로스 + VWAP 위 → +2점   │
  │   둘 중 하나만 → +1점               │
  │   불일치 → 경고 플래그               │
  └──────────────────────────────────────┘

┌─────────────────────────────────────────────────────────┐
│  LAYER 5  리스크 게이트  (1 global call + 종목당 1 call)  │
└─────────────────────────────────────────────────────────┘

  진입 전 최종 리스크 차단

  ① get_upcoming_earnings()  [전체 1회]
       → 10일 이내 실적 발표 티커 → 즉시 제외
       → 이유: IV 크러쉬, 방향 불확실

  ② get_short_data_by_ticker(ticker)
       → 공매도 비율 확인
       → Short Float > 20% + 플로우 불리시 → Short Squeeze 잠재력 (콜 매수 추가 근거)
       → Short Float > 20% + 플로우 베어리시 → 하락 가속 가능 (풋 매수 추가 근거)

  보조 (선택):
  ③ get_congress_trades() / get_insider_ticker_flow(ticker)
       → 의회/내부자 같은 방향이면 확신 +α

┌─────────────────────────────────────────────────────────┐
│  LAYER 6  계약 선정  (최종 후보 종목당 최대 6 calls)      │
└─────────────────────────────────────────────────────────┘

  어떤 계약을 살 것인가

  ① get_flow_per_expiry(ticker)
       → 어느 만기에 플로우가 집중되는지
       → 스마트머니가 선택한 만기를 따라간다
       → W+2/W+3/W+4 중 플로우 집중 만기 우선 선택

  ② get_flow_per_strike(ticker)
       → 어느 행사가에 플로우가 집중되는지
       → 플로우 집중 행사가 = 스마트머니 타겟 레벨
       → GEX 절벽 + 플로우 집중 행사가가 일치하면 최강 신호

  ③ get_options_chain(ticker, expiry)  [W+2, W+3, W+4 각각]
       → 실제 계약 데이터: 프리미엄, 델타, IV, 볼륨, OI
       → 필터 조건:
           delta: 0.30 ~ 0.55
           스프레드율: < 10%
           Vol/OI: > 0.1
           IV: 가급적 < 35%
       → GEX 기반 행사가 + 플로우 집중 행사가에서 선택

  ┌───────────────────────────────────────────────────────┐
  │ CONTRACT SELECTION LOGIC                              │
  │                                                       │
  │ 1순위 행사가: 플로우 집중 행사가 = GEX 절벽 행사가     │
  │ 2순위 행사가: 플로우 집중 행사가 (GEX 불일치)          │
  │ 3순위 행사가: GEX 절벽 기준 ATM+5% (플로우 없음)       │
  │                                                       │
  │ 만기 선택:                                            │
  │   플로우 집중 만기가 W+2 → W+2 진입 (모멘텀 강)        │
  │   플로우 집중 만기가 W+3/W+4 → W+3 기본 추천           │
  │   이벤트/촉매 있으면 → 이벤트 이후 만기 W+4            │
  └───────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────┐
│  LAYER 7  리포트 생성 & 전달                             │
└─────────────────────────────────────────────────────────┘

  5-Section 리포트 조립 → KakaoTalk 발송
```

## MCP 호출 수 최적화

```
Layer 0: 시장 레짐       4 calls  (고정)
Layer 1: 플로우 디스커버리 1 call   (30종목 분석을 1 call로 대체)
Layer 2: 확신 스태킹     4 calls × 8종목 = 32 calls
Layer 3: 가격 레벨       3 calls × 5종목 = 15 calls
Layer 4: 기술 확인       2 calls × 5종목 = 10 calls
Layer 5: 리스크 게이트   1 + 5 = 6 calls
Layer 6: 계약 선정       6 calls × 5종목 = 30 calls
                         ─────────────────────
                         총 98 calls (이전 159 calls 대비 38% 감소)
                         + 신호 품질은 크게 향상
```

## 종합 확신 점수표

```
확신 점수 (MAX 10점):

Layer 1: 플로우 기본      — 통과 여부 (0 or 1) × 2 = 0~2점
Layer 2: 확신 스태킹      — 0~4점 (각 1점)
           · lit_flow 방향 일치
           · 플로우 가속
           · 다크풀 방향 일치
           · OI 급증
Layer 3: 가격 레벨 일치   — 0~2점
           · GEX 방향 + 맥스페인 방향 일치: 2점
           · 하나만 일치: 1점
Layer 4: 기술 컨펌        — 0~2점
           · MACD + VWAP 일치: 2점
           · 하나만: 1점

─────────────────────────
8~10점: TIER 1 — 최대 사이즈 진입
6~7점:  TIER 2 — 보통 사이즈 진입
4~5점:  TIER 3 — 소규모 또는 관망
< 4점:  NO TRADE
```

## 리포트 5섹션 구성

### SECTION 1 — 시장 환경 (GEX + VIX + 선물)

```
데이터: get_market_state + get_greek_exposure_by_ticker(SPY/QQQ)
        + get_futures_indices

출력:
  GEX 환경: 양수 (+$XXXm) / 음수 (-$XXXm)
  해석: [변동성 억제 / 방향성 폭발 구간]
  VIX: XX.X
  선물: ES ±X% | NQ ±X%
  오늘 전략 방향 판정: [풀사이즈 / 50% 축소 / 보류]
```

### SECTION 2 — Market Tide 방향

```
데이터: get_market_tide()

출력:
  콜 프리미엄 $XXXm vs 풋 프리미엄 $XXXm
  비율: X.XX
  센티먼트: [BULLISH / BEARISH / NEUTRAL]
  오늘 전략: [CALL 집중 / PUT 집중 / 선별적]
```

### SECTION 3 — 옵션 플로우 Top 20

```
데이터: get_flow_alerts() → get_ticker_lit_flow()
        + get_dark_pool_trades() + get_open_interest_changes()

출력:
  순위 | 티커 | 방향 | 대형주문 | OI변화 | 다크풀 | 확신점수
  20개 종목 테이블
```

### SECTION 4 — 콜/풋 추천 + 행사가격

```
데이터: get_greek_exposure_by_strike + get_max_pain
        + get_flow_per_expiry + get_flow_per_strike
        + get_options_chain

출력 (종목당):
  현재가 / GEX 절벽 레벨 / 맥스페인 / 다크풀 지지
  추천 계약: [만기] [행사가] [프리미엄] [델타] [IV]
  계약 선택 근거: 플로우 집중 or GEX 절벽 기반
```

### SECTION 5 — 손익분기 / 타겟 / 손절

```
계산:
  BEP = 행사가 + 프리미엄
  1차 타겟 = GEX 절벽 레벨 (도달 시 +50~80%)
  2차 타겟 = GEX 절벽 돌파 후 다음 레벨
  손절 = 프리미엄 -40% OR 다크풀 지지 이탈
  시간 손절 = 만기 3일 전 잔량 청산
  R/R = 타겟 수익 / 최대 손실 (목표 1.5 이상)
```

## 파이프라인이 답하는 핵심 질문

```
Q1. 오늘 이 전략을 할 수 있는 환경인가?
    → Layer 0: GEX 음수 + Market Tide 방향성 뚜렷

Q2. 오늘 주목할 종목은 무엇인가?
    → Layer 1: Flow Alerts가 알려준다 (기술분석 불필요)

Q3. 그 플로우가 진짜인가 (노이즈인가)?
    → Layer 2: 4개 독립 신호 스태킹

Q4. 주가가 어디로, 얼마나 갈 것인가?
    → Layer 3: GEX 절벽 + 맥스페인 + 다크풀 레벨

Q5. 기술적으로도 일치하는가?
    → Layer 4: MA/MACD/VWAP 컨펌

Q6. 숨겨진 리스크는 없는가?
    → Layer 5: 실적, 공매도, 이벤트

Q7. 정확히 어떤 계약을 살 것인가?
    → Layer 6: 스마트머니가 집중한 만기+행사가
```
