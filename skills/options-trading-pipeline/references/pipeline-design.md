## GEX 해석 가이드

```
GEX 양수 (+):
  마켓메이커가 델타 헷지로 주가 상승시 매도, 하락시 매수
  → 주가가 안정화되는 효과
  → 옵션 시간가치 빠르게 소멸
  → 프리미엄 매수 불리, 사이즈 축소

GEX 음수 (-):
  마켓메이커가 델타 헷지로 주가 방향과 같이 움직임
  → 주가 움직임이 증폭되는 효과
  → 방향성 옵션 매수 최적 환경
  → 프리미엄 매수 최적

GEX 절벽 (Cliff):
  특정 행사가에서 GEX가 급격히 감소하는 구간
  → 그 레벨을 넘으면 마켓메이커 헷지가 같은방향으로 전환
  → 주가 가속 발생
  → 콜: 절벽 위 행사가 선택 / 풋: 절벽 아래 행사가 선택
```

## 맥스페인 활용법

```
맥스페인 = 만기일에 옵션 매수자의 손실이 최대화되는 주가
         = 옵션 매도자(마켓메이커)가 가장 유리한 주가

현재가 >> 맥스페인:
  마켓메이커 입장에서 주가를 끌어내리려는 헷지 압력
  → PUT 매수 방향 우호적

현재가 << 맥스페인:
  마켓메이커 입장에서 주가를 올리려는 헷지 압력
  → CALL 매수 방향 우호적

현재가 ≈ 맥스페인 (±2%):
  만기가 가까울수록 여기로 수렴 경향
  → 진입 비추, 방향성 불확실
```

## 다크풀 활용법

```
get_dark_pool_trades():
  대형 기관 블록 거래 방향 확인
  → 매수 블록: 기관이 해당 가격에서 확신을 갖고 매수
  → 매도 블록: 기관이 포지션 청산 중

get_dark_pool_volume_price_group():
  가격대별 누적 다크풀 거래량
  → 볼륨 가장 많은 가격대 = 기관 평균 매수단가
  → 이 레벨이 실질 지지선으로 작동
  → 콜 진입: 이 레벨 위에서 진입 (지지 확인)
  → 이 레벨 아래 이탈: 기관도 손절 → 급락 가능
```

## 계약 선정 로직

```
Step 1: get_flow_per_expiry → 가장 플로우 집중된 만기 선택
Step 2: get_flow_per_strike → 해당 만기에서 플로우 집중 행사가 확인
Step 3: get_greek_exposure_by_strike → GEX 절벽과 교차 확인
Step 4: get_options_chain → 해당 계약 필터링

필터 기준:
  ✓ 델타:    0.30 ~ 0.55 (ATM~약간 OTM)
  ✓ 스프레드: (ask-bid)/mid < 10%
  ✓ Vol/OI:  > 0.1 (당일 거래 활성)
  ✓ IV:      < 35% (프리미엄 매수 전략)

최종 선택: 위 조건 충족 + 플로우/GEX 교차점에 가장 가까운 행사가
```

## 손익 계산 공식

```
BEP (손익분기):
  콜: 행사가 + 프리미엄
  풋: 행사가 - 프리미엄

타겟:
  1차 = GEX 절벽 레벨 (주가 기준)
        → 예상 프리미엄 수익: +50~70%
  2차 = GEX 절벽 돌파 후 다음 레벨
        → 예상 프리미엄 수익: +80~150%

손절:
  프리미엄 손실 -40%
  OR 다크풀 지지선 이탈 (주가 기준)
  OR 만기 3일 전 자동 청산

R/R 최소 기준: 1차 타겟 기준 R/R ≥ 1.3
```
