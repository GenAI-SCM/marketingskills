# Options Contract Scoring Model

## 1. 기술 시그널 점수 (종목 레벨)

### 불리시 점수표 (0–5점)

| 조건 | 점수 | MCP 데이터 소스 | 계산법 |
|------|------|----------------|--------|
| MA 단기 정렬: MA1 > MA2 > MA5 | +1 | get_historical_stock_prices(1d) | close[0] > mean(close[0:2]) > mean(close[0:5]) |
| MA 중기 추세: MA5 > MA20 | +1 | get_historical_stock_prices(1d) | mean(close[0:5]) > mean(close[0:20]) |
| MACD 상향 돌파 (최근 3봉) | +1 | get_historical_stock_prices(1d) | MACD line crossed Signal within 3 bars |
| 가격 > VWAP | +1 | get_historical_stock_prices(5m) | close > VWAP |
| 거래량 스파이크: 오늘 > 5일 평균 × 1.5 | +1 | get_historical_stock_prices(1d) | volume[0] > mean(volume[1:6]) * 1.5 |

**총점 해석:**
- 5점: STRONG CALL ★★★★★ → 즉시 진입 검토
- 4점: CALL ★★★★☆ → 진입 고려 (보조 조건 확인)
- 3점: WEAK CALL ★★★☆☆ → 관망 리스트
- 0-2점: No signal → Skip

### 베어리시 점수표 (0–5점, 역방향)

| 조건 | 점수 |
|------|------|
| MA 단기 역정렬: MA1 < MA2 < MA5 | +1 |
| MA 중기 하락: MA5 < MA20 | +1 |
| MACD 하향 돌파 (최근 3봉) | +1 |
| 가격 < VWAP | +1 |
| 거래량 스파이크 (하락 확인) | +1 |

## 3. 옵션 계약 점수 (0–100점)

### 3-1. 델타 점수 (25점)

```
델타(δ) 값 → 점수:
  0.40 ≤ δ ≤ 0.50 → 25점  (최적: ATM near, 균형잡힌 레버리지)
  0.50 < δ ≤ 0.60 → 20점  (약간 ITM, 낮은 레버리지)
  0.30 ≤ δ < 0.40 → 20점  (OTM, 높은 레버리지 but 낮은 확률)
  0.20 ≤ δ < 0.30 → 10점  (딥 OTM, 로또 성격)
  δ > 0.60        → 15점  (ITM, 프리미엄 비쌈)
  δ < 0.20        → 0점   (제외)
```

### 3-2. 유동성 점수 (25점)

```
스프레드율 = (ask - bid) / ((ask + bid) / 2) × 100

  스프레드율 ≤ 3%  → 25점 (매우 유동적)
  3% < 스프레드율 ≤ 5%  → 20점
  5% < 스프레드율 ≤ 10% → 10점
  스프레드율 > 10% → 0점 (거래 부적합)

Vol/OI 보너스:
  Vol/OI > 2.0 → +5점
  Vol/OI > 1.0 → +3점
  Vol/OI > 0.5 → +1점
  (최대 25점 캡)
```

### 3-3. IV 점수 (25점) — 프리미엄 매수 전략

```
목표: IV가 낮을 때 매수 (cheap premium)

impliedVolatility 값:
  IV < 0.20 (20%) → 25점  (매우 저렴)
  0.20 ≤ IV < 0.30 → 20점
  0.30 ≤ IV < 0.40 → 15점
  0.40 ≤ IV < 0.50 → 10점
  0.50 ≤ IV < 0.60 → 5점
  IV ≥ 0.60 (60%) → 0점  (너무 비쌈)

⚠️ 실적 전 IV 스파이크 시 매수 금지
```

### 3-4. 만기 점수 (25점)

```
목표: 단기 레버리지 극대화

W+2 (10-14일 만기) → 25점  (최대 레버리지, 시간가치 빠름)
W+3 (15-21일 만기) → 18점  (균형, 권장 기본)
W+4 (22-28일 만기) → 12점  (보수적, 시간 여유)
```

## 4. 최종 랭킹 공식

```
종목 최종 점수 = 기술점수(0-5) × 20 + 계약점수(0-100)

Max = 5 × 20 + 100 = 200점

랭킹 기준:
  180-200: TIER 1 — 최우선 진입
  140-179: TIER 2 — 진입 고려
  100-139: TIER 3 — 관망
  < 100:   No trade
```

## 5. 진입/청산 가이드라인

### 진입 규칙

| 조건 | 액션 |
|------|------|
| 기술점수 ≥ 4 + 계약점수 ≥ 70 | 즉시 진입 |
| 기술점수 = 3 + 계약점수 ≥ 80 | 추가 확인 후 진입 |
| 장 시작 후 15분 관망 필수 | 첫 15분 가격 안정 확인 |
| VWAP 재확인 | 진입 시점 가격 > VWAP |

### 청산 규칙

| 시나리오 | 청산 기준 |
|---------|---------|
| 수익 목표 | 프리미엄 +50% (보수) / +80% (적극) |
| 손절 기준 | 프리미엄 -40% |
| 시간 손절 | 만기 3일 전 보유 잔량 청산 |
| 기술 역전 | 반대 방향 점수 ≥ 3 발생 시 청산 |

## 6. 포지션 사이징 가이드

```
단일 포지션 위험 노출 = 전체 옵션 예산의 최대 15%

예: 옵션 트레이딩 예산 $10,000
  - 단일 포지션 최대: $1,500 프리미엄
  - TIER 1: $1,500까지
  - TIER 2: $1,000까지
  - TIER 3: $500 이하 (테스트)
  - 동시 최대 포지션: 5개
```
